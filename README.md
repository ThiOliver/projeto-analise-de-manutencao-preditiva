# projeto-manutencao-preditiva
Projeto final do Módulo 2 do curso Desenvolvedor em IA para Análise Preditiva. Pipeline de classificação binária para prever falhas em máquinas industriais a partir de dados de sensores (temperatura, torque, rotação e desgaste). Inclui análise exploratória, pré-processamento, comparação de 3 modelos de Machine Learning e deploy em Streamlit.
